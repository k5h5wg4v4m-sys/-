# TABYLGA — полное техническое задание для разработки маркетплейса

## 1. Общая информация о проекте

Создай полноценную современную онлайн-платформу объявлений под названием TABYLGA.

TABYLGA — это маркетплейс Кыргызстана, где пользователи могут размещать объявления о продаже товаров, находить нужные товары, связываться с продавцами и покупать товары напрямую.

Основная валюта: кыргызский сом (KGS).

Основной язык: русский и кыргызский.

Платформа должна быть полностью адаптирована для:

- Смартфонов Android.
- iPhone.
- Планшетов.
- Компьютеров.

ВАЖНО: Создай полноценный функциональный продукт с настоящей базой данных, серверной логикой, авторизацией, загрузкой фотографий и работающими функциями. Не создавай демонстрационный макет с неработающими кнопками.

## 2. Регистрация и авторизация

### Регистрация

Регистрация должна осуществляться по номеру телефона Кыргызстана.

1. По умолчанию установлен код страны +996.
2. Пользователь вводит 9 цифр номера телефона.
3. Отправляется настоящий SMS-код подтверждения.
4. После подтверждения номера пользователь создаёт пароль.
5. Пароль необходимо ввести два раза.

### Требования к паролю

Система должна проверять надёжность пароля.

Обязательные требования:

- Минимум 8 символов.
- Хотя бы одна заглавная латинская буква.
- Хотя бы одна строчная латинская буква.
- Хотя бы одна цифра.
- Хотя бы один специальный символ.
- Только латинские символы.
- Запрещены пробелы.

Например: `Tabylga@2026`

Показывай индикатор надёжности пароля: слабый, средний, надёжный.

Если пароли не совпадают, регистрация невозможна.

### Данные пользователя

После регистрации пользователь должен заполнить:

- Год рождения.
- Имя.
- Фамилию.
- Отчество (необязательно).
- Пол: мужской или женский.

Эти данные отображаются в профиле пользователя.

После успешного заполнения пользователь автоматически попадает на главную страницу.

Предусмотри восстановление пароля через подтверждение номера телефона.

## 6. Оплата публикации объявлений

Публикация объявлений является платной.

Стоимость одного дня размещения: 20 сомов.

Пользователь самостоятельно выбирает срок размещения. Например:

| Срок | Стоимость |
|---|---|
| 1 день | 20 сомов |
| 3 дня | 60 сомов |
| 5 дней | 100 сомов |
| 7 дней | 140 сомов |
| 10 дней | 200 сомов |
| 15 дней | 300 сомов |
| 30 дней | 600 сомов |

Сумма рассчитывается автоматически: **Общая стоимость = Количество дней × 20 сомов.**

### Логика публикации

1. Пользователь заполняет объявление.
2. Загружает фотографии.
3. Указывает цену и описание.
4. Выбирает срок размещения.
5. Система автоматически рассчитывает стоимость.
6. Пользователь нажимает «Опубликовать».
7. Сервер проверяет баланс пользователя.
8. Если денег достаточно, необходимая сумма списывается с баланса.
9. Объявление проходит модерацию.
10. После одобрения модератором объявление становится активным.

Если баланс недостаточный:

- Объявление не публикуется.
- Деньги не списываются.
- Показывается сообщение «Недостаточно средств».
- Предлагается перейти к пополнению баланса.

Если объявление отклонено модератором, деньги за неиспользованный период возвращаются на внутренний баланс пользователя.

После окончания оплаченного срока объявление автоматически получает статус «Завершено» и перестаёт отображаться среди активных объявлений.

Предусмотри возможность повторного размещения объявления с новой оплатой.

## 7. Чат

Чат появляется автоматически, когда покупатель впервые пишет продавцу.

В списке чатов отображай:

- Фото профиля.

- Последнее сообщение.
- Время последнего сообщения.
- Количество непрочитанных сообщений.

Внутри чата должны быть:

- Текстовые сообщения.
- Отправка фотографий.
- Время отправки.
- Статус прочтения.
- Информация о товаре, по которому началась переписка.

Сообщения должны сохраняться в базе данных. Реализуй обновление сообщений в реальном времени.

### Чат с поддержкой

Добавь отдельный чат «Поддержка TABYLGA». Пользователь может обратиться к администрации по вопросам:

- Пополнения баланса.
- Проблем с объявлениями.

Администратор должен иметь возможность отвечать через административную панель.

Баланс используется исключительно для оплаты размещения объявлений внутри TABYLGA.

- Пополнение.
- Оплата объявления.

Для каждого объявления: фотография, название, цена, статус, дата окончания, количество оставшихся дней.

Добавь возможность повторной публикации завершённого объявления.

5. Изменение имени.
6. Изменение фамилии.
7. Изменение отчества.
8. Изменение пароля.
9. Кнопка «Выйти из аккаунта».
10. Кнопка «Удалить аккаунт» с подтверждением.

Все изменения должны сохраняться в базе данных.

## 9. Пополнение баланса

### Способы пополнения

1. M BANK.
2. O BANK.
3. SIMBANK.
4. BAKAI BANK.
5. OPTIMA BANK.
6. KOMPANION.
7. DEMIRBANK.

Каждый способ оплаты имеет отдельную карточку. При выборе банка отображаются реквизиты для перевода.

### Реквизиты

Администратор самостоятельно добавляет и изменяет: название банка, имя получателя, номер счёта или карты, дополнительные инструкции, при необходимости QR-код.

Добавь кнопку «Скопировать реквизиты».

### Заявка на пополнение

1. Выбрать банк.
2. Указать сумму пополнения.
3. Перевести деньги по реквизитам.
4. Указать номер транзакции или загрузить фотографию чека.
5. Нажать «Отправить заявку».

После отправки заявка получает статус «На проверке». Уведомление: «Ваша заявка отправлена. Модератор проверит оплату в течение 1 часа».

Статусы заявки: на проверке, одобрено, отклонено.

Если администратор одобряет заявку, система автоматически зачисляет сумму на баланс. Если заявка отклонена, пользователь получает уведомление с причиной отказа.

ВАЖНО:

- Нельзя зачислять деньги автоматически только на основании загруженного чека.
- Зачисление происходит только после проверки администратором.
- Одна заявка не может быть одобрена дважды.
- Все операции должны записываться в историю транзакций.

## 10. Административная панель

Отдельная защищённая панель, недоступная обычным пользователям. Доступ только по роли администратора, назначенной на сервере.

### Главная панель (статистика)

- Общее количество пользователей.
- Количество активных пользователей.
- Количество объявлений.
- Количество активных объявлений.
- Количество завершённых объявлений.
- Количество ожидающих заявок на пополнение.
- Общая сумма пополнений.
- Общая сумма расходов пользователей на публикацию.

### Управление пользователями

- Просматривать всех пользователей.
- Искать пользователя по номеру телефона.
- Открывать профиль пользователя.
- Просматривать его объявления.
- Просматривать историю транзакций.
- Изменять баланс.
- Блокировать и разблокировать аккаунт (с полем причины).

Заблокированный пользователь не может публиковать объявления и отправлять новые сообщения.

### Заявки на пополнение

Администратор видит: имя пользователя, телефон, банк, сумму, фото чека, номер транзакции, дату, статус. Кнопки «Одобрить» и «Отклонить». При одобрении баланс увеличивается автоматически, при отклонении обязательна причина.

### Управление реквизитами

Добавлять банки, изменять реквизиты, удалять способы оплаты, загружать QR-коды, временно отключать способ пополнения.

### Управление объявлениями

Фильтры: активные, на модерации, отклонённые, завершённые. Действия: открыть, посмотреть фото, проверить описание, одобрить, отклонить (с причиной), удалить.

### Жалобы

Администратор видит объявление, пользователя, на которого пожаловались, причину, дату. Может удалить объявление или оставить его активным.

### Поддержка

Просмотр всех обращений и ответы пользователям через чат поддержки.

### Финансовый контроль

Все изменения балансов фиксируются в журнале: кто выполнил операцию, кому изменили баланс, старый баланс, новый баланс, сумма изменения, причина, дата и время.
